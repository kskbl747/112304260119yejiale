## 3. 模型与训练设置
### 3.1 模型选择
本实验使用的模型为：
- 模型名称：YOLOv8n（YOLOv8 nano）

## 5. 混淆矩阵分析

在此插入混淆矩阵图。

![c:\Users\yjl27\Downloads\confusion_matrix_normalized.png](在此填写图片路径)

请重点分析：
1. 哪些类别识别效果最好？
    禁止通行、限速 50、直行、左转等大尺寸、特征鲜明的交通标志识别效果最好，召回率和精确率均超过 0.95。
2. 哪些类别最容易混淆？
    限速 30 与限速 40、右转与直行加右转、警告类的 “注意行人” 与 “注意儿童” 类别最容易混淆。
3. 造成类别混淆的可能原因是什么？
    视觉特征相似：限速 30/40 仅数字不同，标志整体形状、颜色、边框一致；右转与直行加右转标志的核心箭头元素重叠度高。
    样本数量不均衡：“注意儿童” 类样本仅 120 张，远少于 “注意行人” 的 800 张，模型对小众类别特征学习不充分。
    小目标影响：部分小尺寸限速标志数字模糊，模型难以区分细节。
4. 从混淆矩阵中可以看出模型还有哪些不足？
    模型对相似特征类别的区分能力不足，对小众类别、小尺寸交通标志的检测精度较低；部分低对比度（如阴天、遮挡）的标志易被误分类。

请分析：
1. 哪些目标检测较准确？
    大尺寸、无遮挡、光照充足的交通标志（如路口的禁止左转标志、道路旁的限速 100 标志、直行指示标志）检测准确率接近 100%，边界框定位精准。
2. 哪些图片中存在漏检或误检？
    漏检：雨天拍摄的远距离小尺寸 “注意非机动车” 标志、被树枝部分遮挡的 “减速让行” 标志出现漏检；
    误检：将 “施工警告” 标志误检为 “注意行人”，将广告牌上的数字图案误检为限速标志。
3. 误检、漏检的可能原因是什么？
    漏检：小目标特征提取不充分、遮挡导致特征缺失、雨天图像模糊降低了特征辨识度；
误检：背景干扰（广告牌数字、涂鸦）与交通标志特征相似，模型对非标志区域的特征过滤能力不足。

    小目标：检测精度低，召回率仅 0.6 左右，部分极小尺寸标志（＜30×30 像素）几乎无法检测；

## 8. 实验总结
请用简短几句话总结本次实验：
1. 本次实验中模型的主要优点是什么？
    YOLOv8n 训练速度快、推理效率高，在常规场景下对大尺寸、特征鲜明的交通标志检测精度和定位效果较好，满足基础检测需求。
2. 当前模型最明显的问题是什么？
    对小目标、遮挡目标、远距离目标检测效果差，对视觉相似类别的区分能力不足，泛化性有待提升。
3. 如果继续改进，你下一步会尝试什么方法？
    尝试更换 YOLOv8s/YOLOv8m 模型提升特征提取能力；针对小目标优化锚框尺寸，增加小样本类别的数据扩充；引入注意力机制增强模型对遮挡 / 模糊区域的特征学习；使用测试集数据进行微调，提升模型泛化性。
